# F16.02 — Execução e consolidação

Fase 16 — Pré-release e homologação.

[Voltar à fase](README.md) · [Cartão](https://github.com/vlabson/AgroGest/issues/71)

Situação: prevista, ainda não validada como concluída.

## Objetivo

obter e validar aceitação pelo usuário, riscos, decisão de implantação e critérios de reversão.

## Dependência

Conferir a preparação da fase. Atividades transversais ou iterativas podem ocorrer em conjunto quando isso for registrado.

## Atividades específicas

- [ ] Congelar escopo da release
- [ ] Confirmar que todas as funcionalidades previstas estão concluídas ou conscientemente removidas
- [ ] Confirmar critérios de aceite
- [ ] Executar build de release
- [ ] Executar suíte completa de testes aplicável
- [ ] Executar testes de regressão
- [ ] Executar homologação dos principais fluxos
- [ ] Validar dados e migrations
- [ ] Validar configurações de ambiente
- [ ] Validar segurança básica
- [ ] Validar backup/rollback
- [ ] Registrar bugs conhecidos aceitos para a versão
- [ ] Definir número/tag da versão
- [ ] Preparar release notes
- [ ] Obter aprovação para implantação
- [ ] Registrar aceite do usuário para a versão e decisão de seguir ou adiar; distinguir esse aceite da aprovação da visão e da autorização de publicação

## Saída esperada

registro-release.md. Consolidar os resultados e referências em [registro-resultados.md](registro-resultados.md).

## Critério de conclusão

Atividades aplicáveis executadas e resultados registrados, com evidências e pendências identificadas. A aceitação final ocorre na validação da fase.
